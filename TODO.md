- [x] Add a context file API so apps with a static window title can report what the user is doing (first client: a Herdr mod, because Herdr's title can't be set and mods can't reach it).
  - A client atomically writes (temp file + rename) `~/Library/Application Support/ActivityMonitor/context/<bundle_id>.json`, e.g. `dev.herdr.app.json`, containing `{"title": "my-repo / fix login / claude"}`, with an optional `"url"`. It rewrites the file when the context changes and at least every 30s while the app is frontmost.
  - In `Sampler.observe()`, after the locked and idle checks (those still win), if the frontmost app's file exists and is under 60s old by mtime, its `title` and `url` replace the AX values. A stale or missing file falls back to AX, so a dead client can't keep crediting an old title.
  - A malformed file is logged and ignored. No schema change: the values land in `bucket_tally` and flow through `Rules` like any window title. Stays file-only to keep the README's "no network code" promise; document the API in the README.
